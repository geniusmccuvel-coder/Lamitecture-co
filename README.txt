LAMITECTURE & CO WEBSITE

How to publish
  1. Open your GitHub repo, then Add file, then Upload files.
  2. Drag in everything from this folder (keep the folders as they are).
  3. Commit. GitHub Pages republishes in a minute or two.

Typefaces
  Bodoni Moda for headlines and Archivo for everything else (loaded from Google Fonts)

Common edits
  Page titles and descriptions:  the <title> and description lines at the top of each page
  Change a screenshot:           replace the file in assets/img/portfolio/
  Change contact links:          search the pages for info@lamitecture.co.za
  Change colours:                the :root block at the top of assets/css/main.css
                                 (--bg is the royal blue #20309A, --tomato is the red #BB232B)
  WhatsApp link:                 search the pages for wa.me/27687935150 (068 793 5150)

After you publish new pages
  In Google Search Console, open URL Inspection, paste each new address and choose
  Request indexing. In Bing Webmaster Tools, use URL Submission for each one.
